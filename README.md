# Alba ☀️

Tu asistente personal de mañanas: se adapta a tu energía, ritmo y estado de ánimo para que empieces cada día con propósito. **Primero vos, después el mundo.**

Versión independiente de la app que nació en Base44: no necesita servidor ni créditos. Todos los datos se guardan en el dispositivo (con exportar/importar backup en Ajustes).

## Qué hace

- **Mañana**: chequeo rápido (sueño + energía) → Alba sugiere mañana *activa*, *lenta* o *descanso* según cómo estás, tus días de descanso y tus últimas mañanas → plan paso a paso, mensaje motivacional (con voz), música según tus géneros y apps de entreno (MyWhoosh, CoreForm, Grow with Anna). En mañanas lentas o de descanso podés mover el entreno a la tarde, a mañana o al finde. Al final: "¿cómo te sentís ahora?".
- **Despertador**: con Alba abierta (celular cargando) suena un tono suave que va subiendo y te habla con un mensaje. También podés descargar una alarma diaria para tu calendario por si la app está cerrada.
- **Tips de invierno** automáticos según tu hemisferio.
- **Rutina**: semana de lunes a domingo, entrenos pendientes y su historial.
- **Progreso**: promedio de sueño y energía, entrenos, cuántas veces mejoró tu ánimo, racha y tipos de mañana.
- **Ajustes**: nombre, hora de despertar, estilo de mensajes (suave, energético, filosófico, con humor), géneros, ejercicios, link de CoreForm, días de descanso.

## Correrla

```bash
npm install
npm run dev      # desarrollo
npm run build    # genera dist/ para publicar en cualquier hosting estático
```

`dist/` se puede publicar gratis en GitHub Pages, Netlify o Vercel. Desde el celular, "Agregar a pantalla de inicio" la deja como app.
